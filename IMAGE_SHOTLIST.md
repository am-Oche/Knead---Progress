# knead — Image shot list

Every image on the site is driven by `window.KNEAD_IMAGES` in **knead/data.js**. Slot ids are unchanged from the original build.

## How to drop a photo in
1. Shoot / generate at the ratio below, at least the largest width listed.
2. Export each width as **AVIF** (quality ~60) **and WebP** (quality ~80) into `/assets/img/` using the exact filenames (`{file}-{width}.avif` + `.webp`).  
   e.g. `npx @squoosh/cli`, `cwebp`, `avifenc`, or Squoosh.app.
3. In `data.js` flip that slot's `ready` to `true` (or add `{ ready: true }` as the last arg of its `R(...)` call).
4. Reload. If a file is missing or broken the branded fallback shows automatically, never a broken image.

Tip: open `knead/index.html?slots` to see every slot id labelled on the page.

**Budgets:** hero ≤ 150 KB (currently 54 KB AVIF / 62 KB WebP at 736w). Full-bleeds ≤ 250 KB at 2400w AVIF. Cards ≤ 90 KB.
